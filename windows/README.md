# Windows 原版说明与使用教程

本目录存放 **Windows 平台原版助手**，便于对照、备份与在 PC 上使用。

| 文件 | 说明 |
|------|------|
| [`x_blyx_v1.58.exe`](./x_blyx_v1.58.exe) | 原版可执行文件，版本 **1.58**，约 **51 MB** |
| 本 `README.md` | Windows 侧教程与注意事项 |

> **Mac 用户请忽略本目录的运行步骤**，请回到仓库根目录看 [主 README](../README.md)，使用 `python3 main.py`。  
> 该 exe 是 **Windows PE 程序**，无法在 macOS 上直接双击运行（除非走虚拟机 / 远程 Windows，那是最后手段）。

---

## 1. 这个 exe 是什么？

根据静态分析，它大致是：

| 项 | 内容 |
|----|------|
| 形态 | PyInstaller 打包的 Windows GUI 程序 |
| 语言 | Python 3.8 + Cython 编译的业务模块（`.pyd`） |
| 界面 | Tkinter（抽卡 / 金币 / 系统 等选项卡） |
| 图色与键鼠 | 傲甲插件体系（如 `AoJia64.dll` 等，运行时自带或旁路） |
| 游戏对象 | 「百炼英雄」网页版 / 小程序窗口（截图找图 + 模拟点击） |
| 功能画像 | 金币招募抽卡、刷图刷金、竞技场相关、坐标录制等 |

**和本仓库 Mac 版的关系：**

- Mac 版是按同一套 **业务结构重写** 的，**不是** 把 exe 转译到 Mac。
- Mac 版 **不连接** 原作者卡密服务器；Windows 原版是否需要卡密/联网校验，以原作者逻辑为准（历史上存在远程校验相关实现）。
- 两边模板、分辨率、缩放不一致时，识别效果不能 1:1 对标。

## 2. 系统要求（Windows）

- **系统**：Windows 10 / 11（64 位推荐）
- **游戏**：用浏览器打开官方 H5 / 或微信小程序窗口，并 **登录账号**
- **显示**：缩放建议 100% 或固定比例；窗口不要被完全遮挡
- **权限**：允许程序截屏、控制键鼠（部分杀软会拦截）
- **网络**：原版若做版本/卡密校验，需要能访问其服务器；本仓库 **不提供** 卡密、不破解

## 3. 下载与启动

### 3.1 从本仓库获取

1. 打开：https://github.com/chenfugui0416/blyx-mac-helper  
2. 进入 [`windows/`](https://github.com/chenfugui0416/blyx-mac-helper/tree/main/windows)  
3. 点击 `x_blyx_v1.58.exe` → **Download**（约 51MB）  
4. 或用 git（体积较大，克隆会慢一些）：

```bash
git clone https://github.com/chenfugui0416/blyx-mac-helper.git
cd blyx-mac-helper/windows
```

### 3.2 首次运行建议

1. 将 `x_blyx_v1.58.exe` 放到单独文件夹（例如 `D:\blyx\`），避免桌面权限/杀软误杀路径问题。  
2. **右键 → 以管理员身份运行**（若截图/点击失败可再试）。  
3. 若 SmartScreen / 杀软提示未知发布者：自行判断风险；本仓库仅归档文件，**不保证无毒、不保证可商用**。  
4. 若提示缺少运行库：按系统提示安装 VC++ 运行库等（视本机环境而定）。

## 4. 使用前准备（游戏侧）

1. 用 **Chrome / Edge** 等打开游戏官方网页，或打开 **微信小程序** 窗口。  
2. **登录** 游戏账号。  
3. 把窗口放到前台，分辨率尽量稳定，**不要最小化**。  
4. 若要用 **抽卡**：请先手动进入游戏内的 **「招募」** 界面，确保能看到 **金币招募** 相关按钮。  
5. 活动页、大地图、关卡「进入」页等 **不是** 招募页，原版脚本也容易识别失败。

## 5. 推荐操作流程（Windows 原版）

> 原版界面是中文选项卡，具体文案以你本机弹窗为准。下列是通用流程。

### 5.1 绑定游戏窗口

1. 打开助手 exe。  
2. 确认窗口标题关键字能匹配浏览器/微信（如「百炼英雄」）。  
3. 使用界面上的 **绑定窗口 / 选择窗口**（名称因版本略有差异）。  
4. 绑定成功后，脚本才会对该窗口截图与点击。

### 5.2 抽卡（金币招募）

1. 游戏内进入 **招募** 界面。  
2. 在助手「抽卡」相关页配置：  
   - 次数（0 常表示不限，建议先设 **1～3** 试跑）  
   - 是否快速抽卡 / 保底红停止 / 遇红停止等  
3. 点 **开始**。  
4. 观察是否点击金币招募按钮、是否识别到结果并关闭弹层。  
5. 异常时先 **停止**，检查窗口是否被遮挡、是否误进钻石付费界面。

### 5.3 刷金 / 自定义脚本

1. 在「金币」类页面选择默认 BOSS 或自定义脚本。  
2. 自定义脚本常见指令风格（以原版实际支持为准）：传送、移动、等待、开宝箱、回城、点击坐标等。  
3. 建议先短时间试跑，确认路径与传送点正确。

### 5.4 竞技场 / 系统功能

按界面场次、随机点击等选项配置后运行；同样要求游戏停在对应界面。

### 5.5 坐标 / 鼠标录制（若有）

用于采集点击坐标或生成自定义刷图步骤。录制时请保持游戏窗口位置稳定。

## 6. 常见问题（Windows）

### Q1：双击没反应 / 闪退

- 用「以管理员身份运行」  
- 查杀软隔离记录  
- 换目录（非中文路径有时也能减少奇葩问题）  
- 看是否被安全软件删除了同目录 DLL  

### Q2：提示未找到窗口

- 游戏窗口标题是否含「百炼英雄」  
- 是否最小化、是否多显示器坐标异常  
- 浏览器标签标题被改成其它内容时，改关键字或重开标签  

### Q3：找到了窗口但不点击 / 乱点

- 游戏不在目标界面（例如在大地图而不是招募）  
- 浏览器缩放不是 100%，或系统显示缩放 125%/150% 导致模板对不齐  
- 窗口被其它浮层挡住  
- 原版依赖傲甲找图，分辨率变化后需要按原版方式重采/调参（以原版 UI 为准）  

### Q4：会不会耗钻石？

- 原版逻辑里通常有「钻石风险」相关停机设计，但 **不能 100% 保证**  
- 建议先小次数、盯着屏幕试跑  
- 余额不足或界面变成钻石按钮时立刻停止  

### Q5：卡密 / 机器码 / 联网失败

- 原版可能连接作者服务器做校验  
- **本仓库不提供卡密、不提供破解、不维护原作者服务**  
- 若原服务已失效，exe 可能无法完整使用——这是原版限制，不是 Mac 重写版的问题  
- Mac 重写版设计为 **本地可启动、无卡密服务器**

### Q6：能在 Mac 上用 Wine / 虚拟机跑这个 exe 吗？

- 理论上可尝试，但傲甲 + 截屏 + 键鼠权限在 Wine/虚拟机里往往很脆  
- 本项目推荐：**Mac 用仓库源码**；exe 留给真 Windows  
- 虚拟机是最后手段，不是主路线  

### Q7：这个 exe 和 Mac 源码哪个更新？

| | Windows exe | Mac 源码（本仓库主体） |
|--|------------|------------------------|
| 版本标签 | 1.58（原版打包） | 1.58-mac.x（结构重写） |
| 平台 | 仅 Windows | 仅 macOS |
| 引擎 | 傲甲 DLL | CG 截窗 + OpenCV + pynput |
| 卡密 | 原版逻辑 | 已移除 |
| 维护 | 归档对照 | 本仓库持续改校准/引擎 |
