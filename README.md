## 1. 项目是什么 / 不是什么

### 是什么

- 在 **已登录的游戏窗口** 上，用「截图找图 + 模拟点击」做自动化辅助（抽卡、刷金、竞技场等骨架）。  
- **Mac 版**：按 Windows 原版模块结构 **重写**，适配 Retina、CG 窗口截图、用户自采模板。  
- **Windows 版文件**：归档原版 `x_blyx_v1.58.exe`，方便 PC 用户下载与对照。

### 不是什么

- **不是** 游戏客户端，也不替代官方登录。  
- **不是** 把 exe「转译」成 Mac 程序。  
- **不是** 卡密平台 / 盗号工具；Mac 版 **不连接** 原作者卡密接口。  
- **不能保证** 与原版 1:1 行为，也不能保证不误点、不耗钻、不被游戏检测。

### 两条使用路线（请对号入座）

```
你有 Windows PC ？
  ├─ 是 → 下载 windows/x_blyx_v1.58.exe
  │        阅读 windows/README.md 教程
  └─ 否（Mac）→ python3 main.py
                 先「校准」再「抽卡」
                 虚拟机跑 exe = 最后手段
```

## 3. Mac 快速开始

### 3.1 环境

- macOS（Apple Silicon / Intel 均可；推荐 arm64 Python）  
- Python 3.10+  
- 浏览器可打开游戏 H5  

### 3.2 安装与启动

```bash
git clone https://github.com/chenfugui0416/blyx-mac-helper.git
cd blyx-mac-helper
python3 -m pip install -r requirements.txt
python3 main.py
```

### 3.3 系统权限（必做）

打开 **系统设置 → 隐私与安全性**，为 **终端 / Python / 你的 IDE** 勾选：

| 权限 | 用途 |
|------|------|
| **屏幕录制** | 截取游戏窗口 |
| **辅助功能** | 模拟鼠标点击 |
| **输入监控** | 「录制」页监听键盘（可选功能） |

改权限后请 **退出并重启** 本程序。

### 3.4 一分钟验收

1. 浏览器打开游戏并登录。  
2. 助手点 **绑定窗口** 或「校准 → 按关键字绑定」。  
3. **截图预览** 能看到游戏画面 → 引擎基本可用。  
4. 进入 **招募** 界面 → **招募链路自检** 能识别金币按钮 → 再试抽卡。

## 4. Mac 详细教程（校准 → 抽卡）

### 4.1 正确界面很重要

| 游戏画面 | 能否直接抽卡 |
|----------|----------------|
| **招募界面**（有金币招募按钮） | 可以尝试 |
| 大地图 / 主城闲逛 | 不行（先手动点进招募） |
| 活动页「大闹天宫」+「进入」 | 不行（先进入/关掉活动） |
| 登录页 / 加载页 | 不行 |

Mac 版 **以识别到金币招募按钮为准**（`jb100` / `jb90` / `jb0`），不再用过小的装饰图冒充「已在招募页」。

### 4.2 校准页怎么用

1. **刷新窗口列表** → 选中类似  
   `[Google Chrome] 百炼英雄 1440x871` → **绑定所选**  
   或点 **按关键字绑定**。  
2. **截图预览**：确认画面是游戏，不是其它标签。  
3. **招募链路自检**（推荐，别一上来「测全部」）：  
   - 提示「已识别金币招募按钮」→ 可去抽卡页试跑  
   - 提示活动「进入」→ 先点进入，再进招募  
   - 未命中 → 见下一节「框选用户模板」  
4. **测常用 / 测当前**：排查单个模板。  
5. **测全部**：阈值默认很低，会刷一堆噪声匹配；**中途关掉没关系**，不要用它判断「能不能抽」。  
6. **建议阈值 / 应用建议阈值到业务**：把抽卡页阈值调到更合理。  
7. 预览图上 **单击** 取色与逻辑坐标；**拖拽框选** 可保存用户模板。

### 4.3 框选用户模板（识别不准时必做）

Windows 原版小图在 Mac 网页上经常对不齐，这是预期现象。

1. 游戏停在真实按钮可见的界面。  
2. 校准页截图预览。  
3. 在预览上拖拽框住按钮。  
4. 「框选模板名」填写例如：  
   - `jb100` / `jb90` / `jb0`（金币招募）  
   - `jinru`（活动进入，可选）  
5. **保存框选为用户模板** → 会写入 `user_templates/`，**优先于** 内置图。  
6. 再跑 **测当前** 或 **招募链路自检**。

### 4.4 抽卡试跑

1. 打开「抽卡」页。  
2. **抽卡次数先填 1～3**（不要一上来无限）。  
3. 匹配阈值可先用校准建议值，或 0.70～0.82 之间试。  
4. 勾选「保底红停止」等按需。  
5. 确认已绑定窗口且在招募界面 → **开始**。  
6. 出问题立刻 **停止**，用「导出调试图」或校准页保存截图排查。

### 4.5 金币 / 录制 / 竞技场

- **金币**：默认 BOSS 或自定义脚本（传送、移动、等待、开宝箱等）。  
- **录制**：把操作写成脚本再贴到金币页（需输入监控权限）。  
- **系统/竞技场**：配置场次后，在游戏对应界面运行。

这些模块是按原版结构搭的骨架，**依赖模板与界面**；Mac 上同样建议先校准再长时间挂机。

## 9. 常见问题

### Mac：绑定成功但抽卡没反应？

1. 是不是在 **大地图/活动页**？先手动进 **招募**。  
2. 跑 **招募链路自检**，看金币按钮是否命中。  
3. 未命中 → 框选 `jb100` 保存用户模板。  
4. 权限是否给了 **当前用来启动 python 的那个程序**。

### Mac：「测全部」分数很多，是不是识别很好？

**不是。** 低阈值下误匹配很多。只信：  
- 链路自检里的 **金币按钮**；  
- 或你在招募页上 **单模板高分且位置正确**。

### Mac：点了开始乱点别的地方？

多半是模板误匹配。提高阈值、换用户自采模板、确认窗口绑定的是游戏标签而不是助手自身。

### Windows：exe 要卡密？

原版可能有联网校验。详见 [windows/README.md](windows/README.md)。本仓库只归档文件，**不提供** 卡密与破解。

### 克隆仓库很慢？

因为包含约 51MB 的 exe。可以：  
- 网页只下载 `windows/x_blyx_v1.58.exe`；或  
- 只用源码时仍会带上该文件（后续若拆 Release 会再说明）。

### 会不会封号 / 误耗钻石？

任何自动点击都有风险。请小次数试跑、本人盯屏；作者与仓库维护者不承担游戏内损失。

## 10. 技术说明（简要）

### Mac 引擎要点

- 优先 `CGWindowListCreateImage` 按窗口 ID 截图  
- Retina：像素坐标 ↔ 逻辑点坐标用 `scale` 换算后再点击  
- 多尺度 + 灰度/彩色 `matchTemplate`  
- `user_templates/` 优先于 `blyx_mac/assets/images/`  
- 过小原版模板（仅数像素）默认跳过，减少误报  

### Windows 原版要点（归档认知）

- PyInstaller + Python 3.8 + Cython `.pyd`  
- 傲甲 `FindPic` / 点击等  
- 与 Mac 版 **引擎不同、行为不完全一致**  

更细的静态分析若需要，可在本地 `analysis/` 目录查看（未全部推送到本公开仓库）。
